## app-ads.txt について

app-ads.txt はまだ置いていない（AdMob のパブリッシャー ID が決まっていないため）。
また、AdMob はデベロッパー Web サイトの **ドメイン直下**（例: `https://taishi-y.github.io/app-ads.txt`）しか見ないので、
このプロジェクトサイト（`/goukaku-timer-site/` 配下）に置いても認識されない。
`Taishi-Y/Taishi-Y.github.io` のユーザーサイトか、独自ドメインの直下に置くこと。
